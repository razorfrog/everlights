Zones

RSSI above about −90 dBm is comfortable. Near −100 the radio link between the bridge and the roofline controller is marginal, and commands can get lost.

Alerts

You'll get a push when a scheduled change gives up, succeeds only after retries, the bridge stops answering for 10 minutes (and when it's back), or the bridge or roofline controller restarts. Anyone who knows a public ntfy.sh topic name can read it, so use a hard-to-guess name.

Siri & Shortcuts

In the Shortcuts app, add a Get Contents of URL action with one of these links, then Show Result so Siri reads back what happened. Name the shortcut what you want to say, like "Roofline off". These only work on your home Wi-Fi.
